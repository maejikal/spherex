# Oxanium

Variable font used by the explorer. Self-hosted; no runtime font service requests.

- Source: https://raw.githubusercontent.com/google/fonts/main/ofl/oxanium/Oxanium%5Bwght%5D.ttf
- Upstream: https://github.com/google/fonts/tree/main/ofl/oxanium
- License: SIL Open Font License 1.1, retained in `OFL.txt`.
- Weight range: 200–800. CSS requests existing UI weights within that range.
